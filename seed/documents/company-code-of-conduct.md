# Code of Conduct

This public conduct standard applies to every Northline employee. It is the only sample document organization members can view without a department grant.

CONDUCT_PUBLIC_2201

Treat colleagues, customers, and candidates with respect. Harassment, discrimination, and retaliation are prohibited. If you see a problem, tell your manager, HR, or the ethics mailbox. You can report anonymously.

This document does not describe pay, revenue, or security controls. Those records stay inside their departments.
